# Практична робота №3. Командна розробка програми для роботи зі словником

##  Опис проєкту
Цей репозиторій створено в рамках виконання командного завдання. Проєкт являє собою консольну програму на Python для роботи зі словниками, де кожна дія (додавання, пошук, фільтрація, сортування тощо) реалізована у вигляді окремої функції.

Розробка здійснювалася спільно із використанням системи контролю версій **Git** та сервісу **GitHub** через механізм створення окремих гілок (branches), кодування, код-рев'ю та злиття (Pull Requests / Merge Requests).
